# WGU-C195-Appointments-Application
Performance Assesment for Software II - Advanced Java Concepts - C195


Appointments Application

This is an application for scheduling appointments. It is designed for a business with multiple locations and customer bases. The application allows employees to schedule appointments with customers across different regions and locations, and to track customer and appointment information over time.
